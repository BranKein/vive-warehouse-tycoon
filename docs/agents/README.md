# 서브에이전트 공통 지침

이 프로젝트는 여러 에이전트가 같은 작업 폴더에서 동시에 일한다. 아래 규칙은 모든 에이전트에게 적용된다.

## 먼저 읽을 것

1. `PLAN.md` 전체
2. `src/contracts/` 전체 (계층 사이의 약속)
3. 자기 역할의 지침 파일 (`sim.md`, `render.md`, `ui.md`)
4. 기획 원문이 필요하면 `../../ideas/warehouse-tycoon.md` (루트 저장소)

## 규칙

- **자기 디렉터리만 고친다.** 지침 파일의 "고칠 수 있는 곳"에 없는 파일은 읽기만 한다.
- **`src/contracts`와 `src/core`는 고치지 않는다.** 바꿔야 하면 필요한 변경과 이유를 최종 보고에 적는다. 메인 에이전트가 반영한다. 기다리는 동안에는 자기 디렉터리 안에서 우회해 작업을 이어간다.
- **`package.json`에 의존성을 추가하지 않는다.** 필요하면 최종 보고에 적는다.
- **커밋하지 않는다.** 여러 에이전트가 같은 폴더에서 동시에 커밋하면 충돌한다. 커밋은 메인 에이전트가 한다.
- **코드와 주석은 영어로 쓴다.** 화면 문구는 코드에 직접 쓰지 않고 번역 키를 쓴다.
- **수치를 코드에 흩어놓지 않는다.** 밸런스 수치는 `src/content`, 색과 조명은 `src/render/theme`에 둔다.
- **검증한다.** `npx vitest run <자기 테스트 경로>`와 `npx tsc --noEmit`을 돌린다. 다른 에이전트가 작업 중인 디렉터리의 타입 오류는 무시하고, 자기 디렉터리의 오류만 고친다.
- **`npm run dev`를 띄워둔 채로 끝내지 않는다.**

## 최종 보고 형식

1. 만든 것 (파일과 역할)
2. 검증한 방법과 결과
3. 끝내지 못한 것과 알려진 문제
4. `contracts`·`core`·`package.json`에 필요한 변경
