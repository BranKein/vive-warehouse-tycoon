# 서브에이전트 지침: 화면 (render)

Three.js로 3D 화면을 만든다.

## 범위 축소 (2026-10-12 사용자 결정, 아래 내용보다 우선한다)

작동이 먼저다. 모델링과 꾸밈은 뒤로 미룬다. `PLAN.md` 3.13의 "모델링과 꾸밈은 뒤로 미룬다"를 따른다.

- 건물은 색으로 구분되는 상자, 차량은 움직이는 작은 상자, 물품과 폐기물은 양에 따라 높이가 달라지는 상자로 그린다. 평평한 판과 도로, 기본 조명만 둔다.
- 만들 것: `createRenderer`, `ViewSync`(생성·삭제·보간), 카메라, 부지·건물·특별 화물 클릭(`onPick`), 개발용 페이지, 화면과 무관한 계산의 테스트.
- 만들지 않을 것: 차량·건물 모양 다듬기, 지게차 연출, 마을 풍경, 강·부두·활주로 꾸밈, 밤 불빛, 건설·철거 애니메이션, 클릭 반응 애니메이션, 분위기 다듬기.
- 이미 있는 모델 파일은 지우지 않고 늘리지도 않는다. `ModelRegistry`를 거쳐 상자를 등록해, 나중에 함수만 바꾸면 되게 한다.

## 고칠 수 있는 곳

- `src/render/`
- `tests/render/`
- `src/render/dev.html`과 그 진입 파일 (가짜 데이터로 화면만 띄워보는 개발용 페이지)

`src/sim`을 import하지 않는다. `src/contracts`의 `GameSnapshot`만 읽는다. 로직이 완성되기 전이므로 `src/dev/fixtures.ts`의 가짜 데이터로 개발한다.

## 만들 것

`PLAN.md` 3.13을 구현한다.

1. **진입점**: `createRenderer(canvas, options)`가 `contracts`의 `GameRenderer`를 구현한 객체를 돌려준다. `render(prev, curr, alpha, realTimeSeconds)`로 한 프레임을 그린다.
2. **ModelRegistry**: 이름 → `Object3D`를 만드는 함수. 건물 18종, 박스 트럭, 지게차, 운반차, 배, 비행기, 팔레트와 상자, 폐기물 더미, 나무, 집, 울타리. 첫 버전은 기본 도형 조합이다. 등록된 함수만 바꾸면 게임 전체에 반영되어야 하고, 나중에 외부 모델 파일을 불러오는 함수로 바꿀 수 있어야 한다.
3. **Theme**: 색, 재질, 조명, 낮·밤 키프레임(새벽, 낮, 노을, 밤)을 한 파일에 모은다.
4. **Environment**: 네모난 판, 도로와 차선, 잔디, 판 바깥의 마을 풍경(집, 나무, 언덕), 강과 부두, 활주로, 하늘과 해·달, 낮·밤에 따라 바뀌는 조명. 밤에는 창문과 가로등에 불이 들어온다.
5. **ViewSync**: 읽기 모델의 건물·차량·재고·폐기물을 화면 객체와 맞춘다. 생기고 사라지는 것을 처리하고, 직전 틱과 현재 틱 사이를 보간한다. 건물이 지어질 때와 철거될 때 짧은 애니메이션을 넣는다.
6. **물품 표시**: 건물 앞 마당과 하치장에 팔레트와 상자 더미. 양은 로그 스케일로 높이에 반영한다. 차량이 실은 짐도 보인다. 폐기물은 건물 옆 더미로 보인다.
7. **지게차**: 로직에는 지게차 위치가 없다. 건물의 처리 작업 상태를 보고 마당 안에서 움직이는 연출로 만든다.
8. **카메라**: 오른쪽 버튼 드래그로 판 중심 기준 회전과 내려다보는 각도 조절(범위 제한), 스크롤로 확대·축소. 조작이 없으면 천천히 도는 감상 시점으로 바뀌고, 조작하면 돌아온다.
9. **클릭**: 차량·건물을 클릭하면 통통 튀는 반응. 부지와 건물 클릭은 `onPick` 콜백으로 알린다. 특별 화물은 눈에 띄게 표시하고 클릭을 콜백으로 알린다.

## 분위기

- 참고 영상(https://youtu.be/Cv5RSFlfPSM)의 모델링과 움직임: 점토 모형처럼 매끈하고 단순한 형태, 부드러운 그림자, 낮고 넓은 창고와 하역 도크, 흰 박스 트럭, 노란 지게차, 팔레트 위 종이 상자, 막대사탕 같은 둥근 나무, 울타리.
- 색은 영상의 흰색·파란색 대신 포근한 파스텔. 모서리를 둥글려 몽글몽글하게. 오래 봐도 편해야 한다.
- 움직임은 느긋하게. 차량은 부드럽게 가속하고 멈춘다.

## 성능

- 건물 30채, 차량 150대, 상자 더미 수백 개에서 PC 브라우저 60fps.
- 같은 모양은 재질과 형상을 공유한다. 수가 많은 것(상자, 나무)은 인스턴싱한다.
- 그림자는 한 방향 조명 하나만 쓴다.

## 테스트

- Three.js 화면 자체는 단위 테스트하지 않는다. 화면과 무관한 계산(보간, 로그 스케일 더미 높이, 낮·밤 키프레임 계산, 카메라 각도 제한)만 테스트한다.
- 개발용 페이지를 띄워 가짜 데이터로 화면이 나오는지 직접 확인한다.
